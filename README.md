# Tetris

使用 Java Swing 開發的俄羅斯方塊遊戲。

## 功能

- 登入介面
- 圖形化遊戲畫面
- 七種經典方塊
- 方塊旋轉
- 左右移動
- 快速下降
- 消除行判定
- 分數計算
- 暫停功能
- 遊戲結束判定

## 使用技術

- Java
- Java Swing
- AWT Event Handling

## 操作方式

| 按鍵 | 功能 |
|------|------|
| ← | 向左移動 |
| → | 向右移動 |
| ↑ | 旋轉方塊 |
| ↓ | 向下移動 |
| Space | 直接落到底部 |
| D | 向下移動一格 |
| P | 暫停 / 繼續 |

## 執行方式

編譯：

```bash
javac Tetris.java
```

執行：

```bash
java Tetris
```

## 遊戲規則

玩家控制隨機生成的方塊下落。

當某一列被方塊完全填滿時，該列會被消除並獲得分數。

當新的方塊無法生成時，遊戲結束。

## 程式架構

### Shape

負責定義七種俄羅斯方塊及其旋轉邏輯。

### Board

負責：

- 棋盤管理
- 方塊移動
- 方塊碰撞判定
- 消除行
- 分數計算

### Tetris

主遊戲視窗。

### LoginWindow

登入介面。

### TAdapter

處理鍵盤輸入事件。
